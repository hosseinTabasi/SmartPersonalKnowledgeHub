# Welcome

Smart Personal Knowledge Hub keeps your notes, tasks and file paths on this computer.

- Notes support tags, notebooks, pin and archive.
- Tasks track Todo / Doing / Done with optional due dates.
- Search is FTS5 first; Related meaning is hashed TF-IDF cosine.
- Optional ONNX MiniLM is loaded only if Assets/models/minilm.onnx exists.
